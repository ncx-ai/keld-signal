#    diagnostic, so the verdict does not rest on it either way.
#
# 4. `review` is checking EXISTING work for errors: code review, verifying a claim someone made,
#    running a suite to find out whether something is broken, auditing.
#
# 5. `analyze` is reasoning over inputs to reach a conclusion: measuring, evaluating options,
#    computing a number, deciding. The output is a judgement, not an artifact.
#
# 6. `retrieve` is looking things up — where does X live, what does Y do, gather the facts.

# 7. `converse` is discussion, brainstorming, or question-answering that produces no artifact.
